# Plans Archive

Historical record of completed plan pipelines, not the current source of
truth. Full content remains in git history — see each dir's `ledger.md`
for the sanctioned summary of what shipped.

This directory is hidden from default `rg`/agent-grep searches via
`.ignore` (`*`) so archived plans stop polluting live-codebase searches.
Use `rg --no-ignore` or an explicit file Read to reach it deliberately.
